🏥 CareLoop AI

Smart Healthcare Communication & Patient Handover Platform

Built during HAXLR8 3.0 – 24-Hour National Level Hackathon at Maharaja Institute of Technology, Mysore.

📌 About the Project

A modern healthcare web application designed to improve communication, streamline workflows, and provide a proactive digital experience for users.

🚨 Problem Statement

Traditional hospital task management relies on passive dashboards and manual data entry. If staff get pulled into emergencies, clinical tasks are easily delayed or missed, leading to critical communication gaps and unverified task completion.

✨ Key Features

- User-friendly and responsive clinical dashboard interface.
- Two-way interactive AI Voice Agent for automated clinical task verification.
- Speech-to-Text and Text-to-Speech integration using Sarvam AI.
- Real-time audit trail categorizing tasks into self-reported vs. verified status.
- Call history logger with full dialogue transcripts and search capabilities.
- Browser-based voice simulation mode for immediate live testing.

🛠️ Technologies Used

Category| Technologies
Frontend| React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Lucide React, Recharts
Backend| Supabase Edge Functions, Supabase Cron
Voice AI| Sarvam AI Voice Agents, Web Speech API
Database| Supabase PostgreSQL

📂 Project Structure

- "src/components/" – UI components and interactive call simulation modals.
- "src/pages/" – Dashboard pages (Task Management, Calling Center, Call History).
- "src/services/" – Sarvam AI integration and call management handlers.
- "supabase/functions/" – Backend Edge Functions for outbound call triggers and webhooks.

🚀 Getting Started

1. Clone the repository

2. Navigate to the project directory

3. Install dependencies
